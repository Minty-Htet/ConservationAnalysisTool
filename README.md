# Overview

Conservation analysis tool to define location and sequence variation between mice and humans in genomics datasets.

# Repo Contents

- [data](./data): Background files containing known breakpoints and list of one to one orthologous genes.
- [man](./man): Documentation manual generated by roxygen2
- [R](./R): Functions used to do calculations and plotting.
- [tests](./tests): Example files for demonstration purposes.
- [app.R](./app.R): Code to run the shiny app.

- [NAMESPACE](NAMESPACE): Package requirements made by roxygen2

# Installation Guide

## Stable Release

Available on https://weinmannlab.shinyapps.io/ConservationAnalysisTool/ <br>

### Package dependencies

Before attempting to download the shiny tool, make sure to have `R` and the `remotes` package already.<br>
We have tested the tool on R 4.5.2 and it should function with the latest versions of the packages on `CRAN` and `Bioconductor` (as of 2025/12/12). <br>
Here are the imports from CRAN: <br>
```
data.table
GenomicRanges
grid
ggnewscale 
ggplot2
igraph
IRanges
pkgload
R.utils
rappdirs
rtracklayer
stringr
shiny
```
Here are the imports from Bioconductor: <br>
```
GenomicRanges,
IRanges,
rtracklayer
```
Assuming you R already and are using an active R session: <br>
On a machine with 8 cores, 3.49GHz and 16GB RAM the installation and deployment should take about 30 seconds.

### Cloning the Repository

1. Open up R:
```
library('remotes')
remotes::install_github("Minty-Htet/ConservationAnalysisTool") 
```

### Deployment

2. Then:
```
library(ConservationAnalysisTool)
run_app()
```

# Results
The demo list of 1749 genes should take about 16 seconds to run on the website: https://weinmannlab.shinyapps.io/ConservationAnalysisTool/ <br>
Inclusion of 1258 peaks of accessible regions should extend the run time to about 190 seconds.<br>
On a machine with 8 cores, 3.49GHz and 16GB RAM the genes should take about 3 seconds to run. <br>
Inclusion of the peaks should extend the run time to about 90 seconds. <br>
The tool will the following pages: <br>
1. The Inputs and Settings Page. <br>
This is where you will input your gene and peak lists, as well as adjust your assumptions on sizes of your regions of coregulation, etc. <br>
2. The Instructions Page. <br>
This is where the various settings and their meanings are explained. Tips on how to read the plots are also provided. <br>
3. Risky Regions Plot Page <br>
This is where you can see where you genes from the reference species end up in relation to each other on the comparator species. We also label groups of genes near genomic breakpoints. <br>
4. Grouping Heatmaps Page <br>
This is where we show you various plots on how far the genes in the inputted lists are from each other, how these genes are grouped together, whether we were able to identify one-to-one orthologs of those genes in the comparator genome, whether the groups of genes as a whole have orthologs or not, and if those groups have split apart in the comparator genome. <br>
5. Grouping Summaries Page <br>
Summary plots and tables of the number groups or genes by breakpoints, split groups, or in the case of inputted peaks how many of them they are close to the inputted genes. <br>
6. Ortholgous Summaries Page <br>
Summary plots and tables of the number of genes or peaks we were able to find a one to one ortholog for in the comparator genome. <br>
7. Region Size Summaries <br>
Summary plots of the number of different types of groups, and the distribution of the sizes of the groups.
